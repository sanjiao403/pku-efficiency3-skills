# deck-rules — 最小包的版式与证据规则

## 1 页面角色与页数

```
封面(1) → 讲解路线(1) → 问题 → 方法 → 结果×2 → 限制 → 结论   （页数不足时补 结果/备用页）
```

一页一个**主张**（claim，写在演讲备注的 `[主张]` 行）；主张必须能被材料里的一句话锚定。
页数由 `case.json` 的 `slide_count`/`num_slides`/`max_slides` 决定；时长 `duration_min`/`minutes` 只影响讲稿节奏。

## 2 版式硬约束（机检口径，`verify.py`）

| 项 | 约束 | 检查段 |
|---|---|---|
| 出血 | 所有形状在幻灯片内 | B |
| 字号 | 正文 ≥12 pt（图注/页脚/页码/标题豁免） | B |
| 要点数 | 每页 ≤6 条（默认；可用 `spec.rules` 收紧） | C |
| 溢出 | 字符预算估算不超槽位（超了记所需/可用高度） | C |
| 页数 | 与案例指令一致 | C |

估算模型：CJK 字宽 = 字号×1.0，拉丁 ×0.55，空格 ×0.30，行高 ×1.25（±8%）。
生成时按 `need = Σ(1 + len(text)//22) × 22pt` 与槽位高度比较，超限则线性降字号到 12 pt。

## 3 证据规则

- 要点是**材料原文整句**（30–190 字符，句末标点），每条带 `anchor = {source, page, block_id, quote}`；
- 页脚：`来源 <材料名> · p.<页码,…>   <当前>/<总页数>`；
- 演讲备注：`[主张] …` + 每条要点 `- 文本 [来源 材料 p.N 块id]` + `[讲稿] …`；
- **数字**：页面上的每个数字（≥2 位或含小数）必须能在 `source.json.numbers` 里查到，
  否则 `verify.py` D 段失败——这是"不凭空取数"的机检形式；
- 图：本最小包**不裁剪、不重绘、不合成**图；材料若含图无法引用时只保留文字与页码，
  在 `uncertainty`/`limitations` 里说明（宁可少一张图，不造假图）。

## 4 模板与编辑

- 模板只被**读**：`probe()` 取版式名、占位符几何、安全区；内容只进版式槽位（或槽位缺失时用文本框）；
- 无模板 → python-pptx 默认母版 + 16:9 画布，warning 里报明；
- 编辑只作用于被点名的页；**设计指纹** = 幻灯片尺寸 + 主题 `typeface` 集合 + 每个版式的
  `{占位符 idx, x, y, w, h}`；前后不一致即 `template_preserved=false`，并给差异清单；
- 每次编辑留 `versions/<deck>-v0-original.pptx` 与 `-v1-edited.pptx`，`edit_report.ops` 记录每条 op 的
  `status/before/after/kept/dropped/why`。

## 5 降级原则

1. 能做的先做、先落盘（`result.json` 永远写出来）；
2. 不能做的写进 `uncertainty`/`limitations`，并让 `status` 变 `partial`；
3. 不编造：不生成占位图、不重打数字、不伪造渲染件；
4. 渲染器缺失时**不产出 PNG**（没有"几何预览冒充渲染"这条路）。

## 6 与完整包的关系

本目录是**极简可跑版**：`scripts/deck.py`（单文件端到端）+ `scripts/verify.py`（机检）。
完整包（`pkg/`、`pkg-v11/`）另有 PDF 图表裁剪、表格转录、逐页 diff、自检套件与 6 篇 references；
两者共用同一套证据与模板规则，输出契约一致。
