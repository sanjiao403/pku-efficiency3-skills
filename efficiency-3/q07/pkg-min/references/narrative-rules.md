# 叙事与时长预算规则（精简版）

规则的人读口径；脚本内建同一条逻辑（`talkplan.py` 的 ARCS / W / bud / strength）。

## 1. 听众 → 叙事弧

| 弧 | 关键词命中 | 结论强度上限 | 页型顺序（前→后） |
|---|---|---|---|
| committee-defense 答辩 | 答辩/学位/评审/评委/defense/committee/viva | strong | 标题·问题·空白·贡献·方法·方法细节·设置·主结果·次结果·局限·结论 |
| lab-meeting 组会 | 组会/进度/合作者/同事/progress | moderate | 标题·问题·方法·设置·主结果·次结果·局限·结论 |
| reviewer-symposium 评审 | 评审/会议/研讨会/同行/review/symposium | strong | 标题·问题·空白·方法·设置·主结果·次结果·消融·局限·结论 |
| teaching-seminar 教学 | 教学/讲座/学生/teaching/lecture | moderate | 标题·背景·问题·方法·方法细节·主结果·结论 |
| grant-panel 立项 | 立项/申请/项目/基金/grant/proposal | moderate | 标题·问题·空白·方法·设置·主结果·局限·结论 |

无命中用 reviewer-symposium。**换听众要换弧**（顺序、秒数分配、强度上限一起变），不是换措辞。

## 2. 每页密度上限

要点 ≤4 条；单条中文 ≤42 字、西文 ≤96 字（**按条判断语言**）；标题取主张首句（中文 ≤34、西文 ≤60）。
超限处置：合并同义 → 降为备用页 → 删（并记入 `dropped_atoms[]`）。讲稿备注写"讲什么/指哪里/强度"，
不与要点重复。

## 3. 时长预算

```
talk_seconds = (duration_min − qa_min) × 60
内容页数      = slide_count − 备用页数      备用页：slide_count≥12→3，8–11→2，6–7→1
每页秒数      = 按页型权重分配，∑ 必须回到 talk_seconds（去重删页后重新归一化）
页型权重      主结果 1.8 > 方法 1.6 > 次结果 1.4 > 局限 1.3 > 问题 1.2 > 结论 1.2 > 设置 1.1 > 路径 0.9 > 标题 0.6
合格带        0.72×~1.55× 目标 min/页，超出则预算冲突
```

冲突处置（不许静默）：材料够、页数限死 → 减页并留痕；材料不够 → **不注水**，写 `deck_shortfall`
（目标/实际/差额）并把 `status` 降为 `partial`；页面数字/锚点不足 → 该页不上，进备用页或取舍记录。

## 4. Q&A 备用页

来源：未上页 atom（按分值取）。**不计讲述时长**（`seconds=0`）。每页带引用锚点，被追问时只读锚点那句原话与数字；
材料没写的口径是"材料未给出"。备用页接在正文后连续编号。

## 5. 证据强度阶梯

| 强度 | 判据 | 允许措辞 |
|---|---|---|
| strong | 有统计量（p/CI/n/±）且数字可定位 | "显著/优于/提升 X（p=…）" |
| moderate | 有数字或图注，无统计检验 | "在本设置下观察到" |
| weak | 仅文字论断 | 加限定语（初步/可能/仅适用于本材料） |

降级：原文 hedge（may/suggest/可能/初步）不得升为 strong；最后与弧的强度上限取更严者。

## 6. 图注与引用落位

用材料原编号（`Figure N / Table N / 图 N / 表 N`），**不重编号**；引用写成 `material:L行号`；
一图只支撑本页那一句主张；材料没给图就不画图（页面无图表引用即可）；公式只保留原文锚点，不重建排版。

## 7. 反模式 → 判据

| 反模式 | 判据 |
|---|---|
| 摘要/结果逐段搬页 | 要点 >4 或单条超限 |
| 页数与时长脱节 | ∑页秒数偏差 >5% |
| 图表与结论不对应 | 图注编号不在材料里 / 图上没有该数字 |
| 引用编号错位 | 行号在材料中解析不到（verify 报 FAIL） |
| 编造数字 | 页面数字在材料中找不到（verify 报 FAIL） |
| 备注缺失或重复 | 备注与页面 Jaccard >0.8 |
| 用重复页凑页数 | `deck_shortfall` 应为差额登记而非 0 |
