# 02 · 叙事模式（narrative patterns）

页型顺序由画像决定（`ARCS[*].order`）；页型本身在 `KIND / W / MAXB` 三张表里定义。

## 页型库

| 页型 | 承载的唯一主张 | 证据锚点下限 | 要点上限 | 时长权重 | 证据桶（优先序） |
|---|---|---|---|---|---|
| `title` | 本次要带走的一句话 | 0 | 2 | 0.6 | — |
| `problem` | 具体问题与它为什么难 | 1 | 3 | 1.2 | problem → background |
| `gap` | 已有工作没解决的那一格 | 1 | 3 | 1.1 | problem → next_step |
| `contribution` | 要听众记住的创新主张 | 1 | 3 | 1.1 | contribution |
| `method-overview` | 方法骨架（输入→步骤→输出） | 1 | 4 | 1.6 | method → setup |
| `method-detail` | 关键一步的细节与判断条件 | 1 | 4 | 1.3 | method |
| `setup` | 数据/分组/指标（可复核的最小设置） | 1 | 3 | 1.1 | setup |
| `result-1` | **主结果**：一个数字、一个对照、一句结论 | 2 | 3 | 1.8 | result（按效应可用性排序） |
| `result-2` | 结果的边界：什么条件下成立/不成立 | 2 | 3 | 1.4 | result |
| `ablation` | 消融/敏感性：证据强度的来源 | 2 | 3 | 1.2 | result |
| `limitation` | 局限、风险与失效条件（附影响范围） | 1 | 3 | 1.3 | limitation |
| `conclusion` | 结论 + 适用边界（与标题页呼应） | 1 | 3 | 1.2 | contribution → next_step → result |
| `backup-*` | 被追问时翻的那一页 | 1（引用） | 1 | 0 | 未上页 atom |

## 五条叙事规则

1. **页数先定事**：`slides = slide_count`（正文 + 备用严格相等）；页数不够时**减内容不注水**。
2. **主结果优先**：`result` 桶的上页顺序按**效应可用性**排序（含 `±`、含提升/降低动词、显著 p 优先；
   "不显著/差距缩小"降级），不是按出现顺序。
3. **一页一主张**：只有一句 `claim`；要点是**支撑**，不是第二主张。重复主张的页会被合并，空出的位置降级为备用页。
4. **结论页做综合**：`conclusion` 由"最强结果 + 适用边界"合成（`本材料范围内：…；适用边界：…`），不复读某一页。
5. **页型顺序固定、内容可换**：顺序来自画像，内容来自材料；改顺序等于换画像，需在 `archetype_reason` 说明。

## 反模式 → 判据

搬摘要逐段上页 → 要点 >6 或单条 >220 字 ｜ 页数与时长脱节 → ∑秒数偏差 >5% ｜
图表与结论不对应 → 图注编号不在材料 ｜ 用重复页凑页数 → `deck_shortfall` 应记差额而非 0。
